# 🧩 Wrapper Classes

* This branch demonstrates the use of Wrapper Classes in Java to convert primitive data types into objects.
* It focuses on how Java provides object representations for primitive types, enabling them to be used in object-oriented features like collections and utility methods.
* In Java, wrapper classes act as a bridge 🌉 between primitive data types and the object world.
* Each primitive type has a corresponding wrapper class that encapsulates the value inside an object.

The goal of this branch is to understand how primitive data can be handled as objects, 
making programs more flexible and compatible with Java’s object-oriented design.

---

# 🚀 Key Concepts Covered

* 🔄 Autoboxing – Automatic conversion of primitives to objects
* 🔁 Unboxing – Converting objects back to primitives
* 🔢 Parsing – Converting strings into numeric values
* ⚖️ Comparison – Using `equals()` vs `==`
* 📦 Wrapper Utilities – Useful methods like `parseInt()`, `valueOf()`
* 🔒 Immutability – Wrapper objects cannot be changed once created

---

# 💡 Why Use Wrapper Classes

Using wrapper classes provides several advantages:

* 📚 Required for collections (`ArrayList`, `HashMap`, etc.)
* ⚙️ Provides built-in utility methods
* 🔍 Enables object-based operations on primitive data
* ❓ Allows handling of `null` values

---

# 🌿 Branch Purpose

The wrapper-classes branch focuses on demonstrating how primitive data types can be 
converted into objects and used effectively in Java applications, especially in scenarios 
where object-oriented features are required.
