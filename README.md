# ⚙️ Methods

This branch focuses on Java Methods, a core concept of Object-Oriented Programming (OOP) and Java programming. Methods allow you to group reusable blocks of code that perform specific tasks, helping to make programs more modular, readable, and maintainable.

By defining and using methods, you can avoid code duplication, pass data as parameters, and return results efficiently. This branch demonstrates method declaration, invocation, parameter usage, and return types in Java.

---
# 🚀 Key Concepts Covered

* 🏗️ Method Declaration – Defining methods with name, parameters, and return type
* 🔄 Method Invocation – Calling methods to execute a specific task
* ✏️ Parameters & Arguments – Passing data into methods
* 🔙 Return Values – Sending results back from methods
* ⚡ Method Overloading – Defining multiple methods with the same name but different parameters
* 🛠️ Void Methods – Methods that perform actions without returning values


---
# 💡 Why Use Methods

Using methods in Java helps in:

* ♻️ Code Reusability – Write once, use multiple times
* 📖 Improved Readability – Breaking programs into logical units
* 🧱 Better Organization – Structuring code into functional blocks
* 🔧 Simplified Maintenance – Easy to update or modify specific behaviors

---
# 🌿 Branch Purpose

The methods branch demonstrates how to create and use Java methods effectively, showcasing reusable, modular, and well-structured code that forms the foundation for building larger, maintainable applications.
