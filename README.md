# 🌊 Stream API

This branch demonstrates how the Stream API is used to process collections of data in a clean, declarative, and efficient way.

Instead of using traditional loops, the code leverages streams to perform operations like filtering, mapping, and sorting in a more readable and concise manner.

The Stream API helps shift the focus from *how* to process data to *what* needs to be done, improving both clarity and maintainability.

---

# 🚀 Key Concepts Covered

* 🔁 Stream Creation – Converting collections into streams  
* 🔍 Filtering – Selecting elements based on conditions  
* 🔄 Mapping – Transforming data into new forms  
* 📊 Sorting – Ordering elements efficiently  
* 📦 Collecting – Converting streams back into collections  
* ⚡ Lambda Expressions – Writing compact, functional-style code  

---

# 💡 Why Use Stream API

Using the Stream API provides several benefits:

* ✨ Reduces boilerplate code  
* 📖 Improves readability  
* ⚡ Enables efficient data processing  
* 🧠 Encourages functional programming style  

---

# 🌿 Branch Purpose

The `stream-api` branch focuses on refactoring data-processing logic using the Stream API.

The goal is to:
* Replace traditional loops with stream operations  
* Write more expressive and concise code  
* Improve maintainability and scalability
